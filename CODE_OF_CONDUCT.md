# Community conduct

Be respectful, constructive and considerate in issues, pull requests and other project spaces.
Critique code and ideas without personal attacks. Harassment, discrimination, threats, doxxing
and deliberate disruption are unacceptable. Respect privacy and do not publish private reports.

Maintainers may edit or remove inappropriate contributions, pause discussions, or restrict access
according to the severity and repetition of the behavior. Reports should be sent privately to
the repository maintainer through an available GitHub contact channel; do not post personal
information in public issues. If no private channel is listed, request one without naming affected
people publicly. Maintainers should handle reports discreetly and explain moderation decisions
where doing so does not compromise privacy.
